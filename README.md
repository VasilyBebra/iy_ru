# Русификатор для Infinite Yield

Тут нету перевода всего скрипта на данный момент, на данный момент русификатор всего лишь позволяет использовать команды с неправильной раскладкой.

<a href="https://discord.gg/sTvnNeXYxF"><img src="https://files.catbox.moe/klbeou.png" alt="discord" width="48"></a> Лучший скрипт с комадной строкой для Роблокса.

```lua
loadstring(game:HttpGet("https://github.com/VasilyBebra/iy_ru/raw/refs/heads/main/source.lua"))()
```

 - На данный момент 400 команд
 - Открытый исходный код
 - 7+ лет разработки (Оригинала)
